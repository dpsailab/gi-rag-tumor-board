# Anonymized Dataset

This folder contains the anonymized dataset used for the analyses reported in the manuscript.  
The dataset is provided **exclusively for reproducibility of the published results**.

Due to data protection and ethical constraints, the original clinical cases and full tumor board recommendations **cannot be shared**.

---

## Dataset description

The dataset is provided as a single CSV file:
```bash
Tumorboard_ChatGPT_anomyzed_dataset.csv
```


Each row corresponds to **one tumor board case**.  
All patient-identifying information and clinically reconstructable details have been removed or irreversibly anonymized.

---

## Core patient and case metadata

| Column | Description |
|------|-------------|
| `case_nr` | Anonymous case identifier |
| `presentation` | Presentation type (1 = first presentation, 2 = follow-up) |
| `age` | Patient age at presentation |
| `gender` | Patient gender (f = female, m = male) |
| `tumour_type` | Tumor entity (esophageal, gastric, pancreatic,colorectal and hepatobiliary) |

---

## Tumor board reference

| Column | Description |
|------|-------------|
| `anonymized_tumorboard_recommedation` | **Highly anonymized and simplified tumor board recommendation**, stripped of all clinical details and reduced to its core decision logic |
| `anonymized_tumorboard_recommedation_treatment` | Final treatment class derived from the tumor board recommendation, according to predefined evaluation criteria |

⚠️ **Important**  
The original tumor board recommendations and full clinical case descriptions are **not included**.  
The provided recommendation has been intentionally simplified to prevent any direct or indirect reconstruction of individual cases.

---

## Model-generated recommendations

For each evaluated framework and model variant, three columns are provided:

1. **Raw model output**  
2. **Final treatment classification**  
3. **Concordance with tumor board decision**

### Example structure (repeated for all models)

| Column | Description |
|------|-------------|
| `No retrieval_4o-mini` | Raw response generated by the model |
| `No retrieval_4o-mini_treatment` | Final treatment classification derived from the model output |
| `No retrieval_4o-mini_treatment_concordance` | Concordance with tumor board (1 = concordant, 0 = non-concordant) |

This structure is repeated for all evaluated setups, including:
- No retrieval  
- Assistant with guidelines  
- RAG with full corpora  
- RAG with selected corpora  
- Rewritten (rw) variants  
- GPT-4o and GPT-4o-mini variants  

The classification rules used to derive `_treatment` columns are documented in:
```bash
../experiments/evaluation.md
```

## Retrieval metadata (RAG-specific)

### Retrieved chunk indices

| Column | Description |
|------|-------------|
| `Chunk Indices_RAG Full Corpora` | Indices of retrieved chunks for RAG with full corpora |
| `Chunk Indices_RAG Selected Corpora` | Indices of retrieved chunks for RAG with selected corpora |
| `Chunk Indices_rw_RAG Full Corpora` | Indices for rewritten queries with full corpora |
| `Chunk Indices_rw_RAG Selected Corpora` | Indices for rewritten queries with selected corpora |

These columns enable **Jaccard similarity analyses** between retrieval strategies  
(see `../analysis/analysis.py`).

---

### Retrieved charts count

| Column | Description |
|------|-------------|
| `Charts N_RAG Full Corpora` | Number of retrieved chunks containing chart information |
| `Charts N_RAG Selected Corpora` | Same for selected corpora |
| `Charts N_rw_RAG Full Corpora` | Same for rewritten queries |
| `Charts N_rw_RAG Selected Corpora` | Same for rewritten queries with selected corpora |

These columns are used to quantify **retrieval behavior and evidence exposure** across RAG configurations.

---

## Intended use and restrictions

- This dataset is provided **solely to allow reproducibility of the analyses and results reported in the manuscript**.
- The data **must not** be used to attempt:
  - Reconstruction of individual cases  
  - Identification of patients or institutions  
  - Clinical decision-making  
- Any reuse, redistribution, or secondary analysis outside the scope of reproducibility is **explicitly prohibited**.
